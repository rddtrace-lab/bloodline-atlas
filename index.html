Accuracy validation

Against a human-curated reference

Gemma (UBC) curators annotate each dataset's design by hand. Labels compared sample by sample; 95% CIs from a bootstrap over datasets. Method

Against the RNA itself

ARCHS4 expression: within-study AUCs pooled by random-effects meta-analysis (0.5 = no signal). Method

Internal consistency tests

Tests run without human annotation (references built from the structured fields by rules written apart from the model). Values: share, 95% CI, n.

For agents

Everything is static JSON over HTTPS with CORS open; no key, no rate limit beyond the host's. Start at api/index.json (counts, endpoints, field definitions) or llms.txt.

GET api/studies.json                 every study (accession, title, samples, types, events)
GET api/studies/{PRJ...}.json        one study: samples, all attributes, runs, labels
GET api/lookup/{last 2 chars}.json   sample/run accession -> study accession
GET data/*.csv.gz                    bulk tables (samples, runs, attributes, studies, labels)

Example: a run SRR12345678 → api/lookup/78.json → its study → api/studies/PRJNA….json.

Sources: NCBI SRA and BioSample, EMBL-EBI ENA. Metadata as deposited by the submitters; labels and harmonisation CC BY 4.0. Labels are machine-made; see the quality section before relying on them.
